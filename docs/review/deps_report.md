## 4. Проблема с драйвером БД

`psycopg2-binary` — драйвер для psycopg2. Но SQLAlchemy 2.x при подключении к PostgreSQL импортирует `psycopg` (v3), если URI имеет вид `postgresql://`. Это подтверждено ошибкой при запуске:

**Решение:** заменить `psycopg2-binary` на `psycopg[binary]` (v3). Либо использовать URI `postgresql+psycopg2://...` и оставить `psycopg2-binary`.
